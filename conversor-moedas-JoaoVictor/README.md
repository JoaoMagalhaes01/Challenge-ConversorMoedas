
# Conversor de Moedas (Java)

Projeto de conversor de moedas utilizando API de câmbio.

## Funcionalidades
- Consumo de API de taxas de câmbio
- Conversão entre moedas
- Menu interativo no console
- Leitura de JSON com Gson

## Tecnologias
- Java
- HttpClient
- Gson

## Como usar

1. Crie uma conta em:
https://www.exchangerate-api.com/

2. Substitua SUA_API_KEY em ApiClient.java

3. Execute:

Main.java

## Conversões disponíveis

- USD -> BRL
- BRL -> USD
- USD -> EUR
- EUR -> USD
- USD -> ARS
- ARS -> USD
